# Security Policy

This is an early, experimental hobby project, maintained on a best-effort basis.
There are no releases or supported versions yet — assume `main` is the only line.

## Reporting a vulnerability

**Please don't report security issues through public GitHub issues.**

Instead, use GitHub's
[private vulnerability reporting](https://github.com/JaimeOrtegaxyz/darkroom/security/advisories/new).

Helpful details, if you have them:

- The type of issue (e.g. secret exposure, injection, auth bypass)
- Where in the source it lives, and how to reproduce it
- A proof of concept, and the impact you see

I'll do my best to acknowledge and look into reports, but can't promise a fixed
timeline. Credit is offered once anything is addressed, unless you'd rather stay
anonymous.
